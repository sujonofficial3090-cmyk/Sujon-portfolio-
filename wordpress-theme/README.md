# Soft Emboss Studio — WordPress Theme & Elementor Template Kit

Welcome to the official WordPress edition of **Soft Emboss Studio**! This theme brings the luxury, tactile Neumorphic design, interactive 3D particle letter canvas, fluid custom cursors, and signature preloader directly into WordPress with **100% native Elementor drag-and-drop support**.

---

## 🚀 Quick Setup Guide (বাংলায় নির্দেশিকা)

### ১. থিম ইনস্টল করা (Install Theme):
1. আপনার ওয়ার্ডপ্রেস অ্যাডমিন প্যানেলে লগইন করুন (`yourdomain.com/wp-admin`)।
2. বাম পাশের মেনু থেকে যান: **Appearance > Themes**।
3. উপরে **Add New Theme** বাটনে ক্লিক করুন, তারপর **Upload Theme**-এ ক্লিক করুন।
4. `soft-emboss-theme.zip` ফাইলটি সিলেক্ট করে **Install Now** বাটনে ক্লিক করুন।
5. ইনস্টল সম্পন্ন হলে **Activate** বাটনে ক্লিক করুন।

### ২. এলিমেন্টর প্লাগইন ইনস্টল করা (Install Elementor):
1. বাম পাশের মেনু থেকে যান: **Plugins > Add New**।
2. সার্চ বক্সে লিখুন: `Elementor`।
3. **Elementor Website Builder** প্লাগইনটি **Install** ও **Activate** করুন (ফ্রি ভার্সন দিয়েই চলবে)।

## 🎨 ১-ক্লিকে টেমপ্লেট ইমপোর্ট করা (1-Click Import):

আমরা ২টি সহজ উপায় দিয়েছি, আপনার পছন্দমতো যেকোনো একটি ব্যবহার করুন:

### উপায় ক: এলিমেন্টর টেমপ্লেট লাইব্রেরি দিয়ে (সবচেয়ে সহজ ও দ্রুত):
1. ওয়ার্ডপ্রেস ড্যাশবোর্ডে **Pages > Add New Page**-এ যান।
2. পেজের নাম দিন (যেমন: **Home**)।
3. ডানপাশের Page Attributes / Template অপশনে গিয়ে সিলেক্ট করুন: **Soft Emboss Elementor Full Width**।
4. পেজটি **Publish** করুন এবং উপরে বড় **Edit with Elementor** বাটনে ক্লিক করুন।
5. এলিমেন্টর এডিটর ওপেন হলে মাঝখানে ধূসর রঙের **Folder Icon (Add Template)**-এ ক্লিক করুন।
6. উপরের ডান কোণায় থাকা **Up Arrow (Import Template)** আইকনে ক্লিক করুন।
7. `wordpress-theme/soft-emboss/demo-content/elementor-template.json` ফাইলটি সিলেক্ট করে আপলোড করুন।
8. আপলোড হওয়ার পর তালিকায় **Soft Emboss Studio Home Template** দেখতে পাবেন। পাশের **Insert** বাটনে ক্লিক করুন।
9. **বুম! 🎉 সম্পূর্ণ ওয়েবসাইট ১-ক্লিকে হুবহু চলে আসবে!**

### উপায় খ: One Click Demo Import (OCDI) প্লাগইন দিয়ে:
1. **Plugins > Add New**-এ গিয়ে `One Click Demo Import` সার্চ করে ইনস্টল ও অ্যাক্টিভ করুন।
2. **Appearance > Import Demo Data**-তে যান।
3. **Soft Emboss Studio Full Demo** সিলেক্ট করে **Import**-এ ক্লিক করুন।
4. অটোমেটিক ডেমো পেজ তৈরি হয়ে যাবে।

## 🛠️ এলিমেন্টর দিয়ে যেভাবে এডিট করবেন:

পেজটি `Edit with Elementor`-এ ওপেন করলে বামপাশের উইজেট প্যানেলে একটি নতুন ক্যাটাগরি দেখতে পাবেন:
👉 **"Soft Emboss Elements"**

এতে রয়েছে নিচের কাস্টম উইজেটগুলো:
1. **Soft Emboss: Hero Section:**
   - নিজের নাম ("SUJON"), সাবটাইটেল, বায়ো এবং বাটন লিংক পরিবর্তন করুন।

2. **Soft Emboss: Services Grid:**
   - ড্র্যাগ অ্যান্ড ড্রপ করে নতুন সার্ভিস কার্ড যোগ করুন, আইকন ও লেখা এডিট করুন।
3. **Soft Emboss: Project Showcase:**
   - আপনার আসল কাজের স্ক্রিনশট ছবি ও লাইভ লিংক আপলোড করুন।
4. **Soft Emboss: Skills & Stack:**
   - আপনার টেকনোলজি ও স্কিলগুলো গ্রুপ আকারে ক্যাটাগরি করে সাজান।
5. **Soft Emboss: Experience Timeline:**
   - আপনার কাজের অভিজ্ঞতা, শিক্ষাগত যোগ্যতা ও বছর পরিবর্তন করুন।
6. **Soft Emboss: Client Reviews:**
   - ক্লায়েন্টদের নাম, রিভিউ ও রেটিং এডিট করুন।
7. **Soft Emboss: Contact Section:**
   - আপনার পার্সোনাল ইমেইল, লোকেশন এবং যেকোনো Contact Form 7 / WPForms শর্টকোড বসিয়ে দিন।
