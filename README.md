1. OVERALL VISUAL STYLE

The entire website uses a soft neumorphic / embossed UI style.

This effect is extremely important and MUST be present throughout the website.

The design should feel like every section/card is softly raised from the background.

Use:

Very light warm-gray/off-white background

Soft raised surfaces

Subtle inner/outer shadows

Soft highlights

Very subtle dark shadows

Rounded corners

Low-contrast borders

Gentle depth

Clean premium appearance

Avoid:

Flat cards

Strong black shadows

Hard borders

Glassmorphism

Excessive gradients

Heavy drop shadows

Sharp corners

Generic Bootstrap-style cards

Standard flat buttons

Neumorphic direction

Use a background close to:

#F1F0F4

Cards should use a similar light surface color.

Use soft dual-direction shadows approximately like:

-6px -6px 12px rgba(255,255,255,0.85)

and

6px 6px 12px rgba(190,188,195,0.35)

Adjust the values visually so the result matches the screenshot.

Use subtle inset shadows where necessary for buttons, inputs and smaller components.

The effect must remain soft, subtle and embossed, NOT dark or dramatic.
